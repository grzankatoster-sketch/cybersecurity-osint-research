Panel OSINT

Lokalnie (127.0.0.1). Tylko dane własne, firmowe lub jawne, w ramach zlecenia.

Wyszukiwanie po nazwie użytkownika

Nasz silnik (~5800 serwisów, ocena pewności, kraj i powiązania kont). Ta sama nazwa nie oznacza tej samej osoby: trafienie to trop, nie dowód.

Linki do profili w raporcie otwieraj w Tor Browserze. Zwykła przeglądarka pokaże serwisowi Twoje IP.

Meta: Threads, Instagram, Facebook

Każdy wynik ma oznaczone źródło: oficjalne API albo link do ręcznego sprawdzenia. Zgodny nick nie potwierdza tożsamości. Brak wyniku nie dowodzi braku konta.

Threads API: publiczny profil po dokładnym nicku

Tylko publiczne profile z co najmniej 100 obserwującymi. Bez zatwierdzenia przez Meta (App Review) działa wyłącznie dla kont Meta.

Threads API: publiczne posty po frazie

Bez zatwierdzonego uprawnienia threads_keyword_search API przeszukuje tylko posty właściciela tokenu.

Instagram API: konto profesjonalne po nicku (Business Discovery)

Widzi tylko konta profesjonalne (Business/Creator), nie prywatne ani osobiste: brak wyniku nie dowodzi braku konta. Wymaga tokenu i numeru konta właściciela (INSTAGRAM_ACCESS_TOKEN, INSTAGRAM_USER_ID).

Facebook API: publiczne dane Strony po id lub nazwie

Tylko Strony (nie profile osób prywatnych). Cudze Strony wymagają funkcji Page Public Content Access / Page Public Metadata Access zatwierdzonej przez Meta (App Review); bez niej wynik to brak uprawnień. Token: FACEBOOK_ACCESS_TOKEN.

Linki do ręcznego sprawdzenia (Threads, Instagram, Facebook)

Nic nie jest pobierane automatycznie: otwierasz strony sam. Strona logowania albo błąd w przeglądarce nie oznacza braku konta.

Konfiguracja API

Tokeny tylko po stronie panelu: zmienne THREADS_ACCESS_TOKEN, INSTAGRAM_ACCESS_TOKEN + INSTAGRAM_USER_ID, FACEBOOK_ACCESS_TOKEN albo plik poza repozytorium (~/.osint/meta.env). Wartości nie są pokazywane.

E-mail i domena

Tylko własne domeny lub ze zgodą właściciela. Wynik to trop, nie dowód.

theHarvester: subdomeny i adresy z publicznych źródeł

HIBP: wycieki źródłowe domeny

HIBP: hasło w wyciekach

Oficjalne API. Do sieci idzie tylko 5 znaków skrótu SHA-1. Tylko własne hasła.

HIBP: najnowsze wycieki w katalogu

Audyt DNS domeny

SPF, DMARC, DKIM, DNSSEC, MTA-STS, CAA. Tylko publiczne rekordy.

Numer telefonu

Offline: format, kraj, typ linii i plan numeracyjny. Operator to pierwotny przydział — mógł być przeniesiony. Panel nie szuka numeru w sieci i nie lokalizuje telefonu.

Metadane zdjęć

Plik lub folder na tym komputerze. Analiza lokalna, mapa GPS jeśli są geotagi. Na końcu wyniku: gdzie ręcznie sprawdzić pochodzenie zdjęcia (TinEye, Google Lens, Bing, Yandex) i miejsce z GPS (Copernicus). Panel niczego tam nie wysyła; wgrywaj tylko kopie bez metadanych i nie szukaj po twarzach.

Skan celu

Jeden cel, kilka narzędzi po kolei i raport zbiorczy. Domena: DNS, HIBP, theHarvester. E-mail: DNS i HIBP domeny (część przed @ nie jest wysyłana). Login: nazwa użytkownika i linki Meta. Błąd narzędzia nie oznacza braku wyniku.

Sprawa: osoby, numery, twierdzenia, kandydaci

Sprawy leżą wyłącznie w panel/wyniki/sprawy; innych katalogów panel nie przyjmuje. Każda zmiana trafia do dziennika audytu sprawy. Kandydat profilu i twierdzenie o relacji wymagają Twojego potwierdzenia; nic nie uruchamia się samo.

Nowa sprawa

Tworzy sprawę offline: kandydaci nazw użytkownika to hipotezy, nic nie jest wysyłane.

Szukaj profili po nazwisku

Imię i nazwisko oraz kontekst trafiają do dostawcy wyszukiwarki (Brave Search API; klucz BRAVE_SEARCH_API_KEY czyta panel po swojej stronie, nie z formularza). Zapytania: nazwa w cudzysłowie z site:facebook.com, site:instagram.com, site:threads.com. Kanał: BRAVE_PROXY albo połączenie bezpośrednie (nie Tor). Wynik to linki do możliwych profili do Twojego przeglądu: nie wszystkie konta i nie ustalenie tożsamości. Strony profili, obrazki i podglądy nie są pobierane.

Limity egzekwuje backend: wywołań 1-12 (ponowienie też się liczy), wyników 1-20, kandydatów 1-100, czas 10-120 s. Bez stronicowania. Limit dotyczy liczby wywołań, nie kwoty.

Kandydat z Twoim materiałem (bez sieci, działa bez klucza)

Podaj adres i tekst, który sam skopiowałeś (do 20 000 znaków). Analiza lokalna: odnośniki, identyfikatory z adresów, wzmianka nazwy. Tekst traktujemy jako dostarczony przez Ciebie, nie jako zweryfikowaną kopię strony; tekstu nie zapisujemy: w sprawie zostaje tylko skrót i ustalenia z dosłownym dowodem. Adres z e-mailem, telefonem albo tokenem jest odrzucany.

Twierdzenie o relacji (wymaga potwierdzenia)

Zapis informacji ze źródła, nie ustalenie: wspólne nazwisko, adres czy numer niczego tu nie dodają. Druga osoba nie jest badana.

Kontekst numeru (plan numeracyjny, offline)

Region planu numeracyjnego to obszar przydziału puli numerów, nie miejsce urządzenia. Numer nie jest wiązany z osobą.

Operator z ręcznej weryfikacji (osobna obserwacja)

Runda kandydatów profili (username-engine)

Jedno kliknięcie = jedna runda w budżecie poniżej. Trafienia to kandydaci do Twojego przeglądu; brak trafień albo błąd serwisu nic nie mówi o osobie.

Laboratorium: ustalenia i blokery

Status projektu z kontrolowanego przeglądu. Szczegółowe dowody są w raportach audytowych; ta zakładka nie pokazuje sekretów ani danych spraw.
